Look for

  • Multi-select is a choice with Multiple => true.
  • Hotspot takes a point: Answers => 28,64. The hit radius is a percentage of the image.
  • Diagram takes targets: Targets => Handle spot @ 76,52, then Correct => Handle @ Handle spot.
  • Classification puts items in buckets with Correct => Item @ Bucket.
  • Every one of these is also a button in a list, so a keyboard can answer without a mouse.
