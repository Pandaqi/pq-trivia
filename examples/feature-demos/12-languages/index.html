Look for

  • The file name decides the language: questions.en.trivia, questions.nl.trivia.
  • Questions line up by ID. Without one, position inside the round does it.
  • Switch while a question is on screen: the text and the interface change, the answer you typed stays.
  • One language in one file also works, with a Language line per block.
