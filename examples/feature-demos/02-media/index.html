← all demos 02 · Media A file is a media item. The extension decides how it plays.

Look for

  • Media => photo.svg { alt="…", credit="…" }. The options are inside the braces.
  • Audio carries a captions track and a transcript. The transcript loads on open, never before.
  • Video has a poster and playsinline. No autoplay with sound.
  • PlayLimit => 1 removes the player after one press.
  • An answer that is only a file is shown as that file, not as text.

The clip and the fjord are downloaded files, not drawings: a CC0 WebM from MDN and a WebP from the sample gallery. The poster is a frame from the clip.
