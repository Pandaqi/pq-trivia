← all demos 04 · Layout Layout names, five built-in classes, three kinds of background.

Look for

  • Layout takes center, compact, quote or full-bleed. A theme can add its own.
  • Class adds a class to the slide. The five short names ship with Paper: center, dark, invert, quote, spotlight.
  • Background reads color:, image:, gradient: or none.
  • Text and answers use the same tokens, so a theme moves both.
