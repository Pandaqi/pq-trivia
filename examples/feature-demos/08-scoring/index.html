← all demos 08 · Scoring Partial credit, a penalty, a streak, a bet, three lifelines.

Look for

  • Scoring => partial gives a share per right answer. per-correct pays each one separately.
  • ScoringPreset => negative costs a quarter of the question for a wrong answer. A skip is free.
  • Streaks => true pays 1.5× from three right, 2× from six.
  • Wager => true puts points on the line. The bet is capped at the question's score.
  • Lifelines cost points. 50/50 needs a choice question; extra time buys seconds; ask the room is what it says.
  • Teams adds a name box on the start screen. One screen, one badge to pass around.
