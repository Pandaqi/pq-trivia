← all demos 07 · Timers One clock per question, one per round, one for the whole quiz.

Look for

  • DefaultTimer => 15 gives every question that names no timer one.
  • Timer => 0 means this question has none.
  • RoundTimer is one clock for a whole round. QuizLimit counts the quiz down; without it the clock counts up.
  • TimerSound => true beeps in the last five seconds. It needs a click first, which the Play button already gave it.
  • When time runs out the question is marked expired and the field stays open. TimerStrategy decides what next: continue, expire or skip.
