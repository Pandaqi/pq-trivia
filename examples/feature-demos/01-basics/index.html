← all demos 01 · Basics Eight types, inline formatting, a code block. All in one text.

Look for

  • One Question block per type. No extra code.
  • Hints appear one click at a time. Sources sit underneath.
  • Answers accept the same formatting as the question: bold, links, even images.
  • The last hash block is an End screen with its own buttons.

Play it with the keyboard: arrows for questions, a for the answer, h for a hint.
