← all demos 13 · Extend A widget in its own sandbox, a toolbar button, the event stream.

Look for

  • Script => widget.html loads the widget into a sandboxed iframe with an opaque origin. It cannot read the page, the quiz or the answers.
  • Off unless the host says AllowScripts => true. The page can also pass it in code.
  • The widget talks over postMessage: pq:ready, pq:resize, pq:response, pq:diagnostic.
  • quiz.actions.add() puts a button in the toolbar. quiz.on() gives you every event on the page.
