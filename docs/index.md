## What it is

Write questions in a file you can email. Open a page. Play.

- Rounds, hints, timers, explanations, media, scoring.
- Interactive play with real grading and a results page.
- Print a clean handout, an answer sheet and a grade table.
- Works from a folder on a USB stick. No account, no backend.
- Optional live mode for phones. Separate bundle, zero weight by default.

## Three sentences of history

V2 shipped and sold quizzes at The Wayward Melody. V3 rebuilds it around a
headless core: parse, plan, play and grade without a DOM. Same text, better
bones.
