## What it is

Write questions in a file you can email. Open a page. Play.

- Rounds, hints, timers, explanations, media, scoring.
- Interactive play with real grading and a results page.
- Print a handout, an answer sheet and a grade table.
- Works from a folder on a USB stick. No account, no backend.
- Phones can join a live room. Separate bundle, off by default.

the same text and rebuilds the engine: parse, plan, play and grade without a
DOM. Old files still work.
